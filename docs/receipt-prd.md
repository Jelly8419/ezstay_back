## 15. 영수증 발급

(현금영수증, 전자세금계산서)

- 내용
    
    ## 15.1 정책 목적
    
    본 정책은 EZstay에서 발생하는 거래에 대해
    
    **현금영수증 및 전자세금계산서 등 세법상 증빙 발급 기준을 명확히 정의**한다.
    
    본 정책은 다음을 해결한다:
    
    - 어떤 거래에 증빙이 필요한지
    - 누가 발급해야 하는지
    - 카드 결제와 현금 결제의 차이
    - 플랫폼 수수료와 임대료의 처리 기준
    
    ---
    
    ## 15.2 증빙 정의
    
    증빙이란 다음 문서를 의미한다:
    
    - 신용카드 매출전표
    - 현금영수증
    - 전자세금계산서
    
    ---
    
    ## 15.3 최상위 원칙 (절대 기준)
    
    ```
    1. 증빙은 “공급자 기준”으로 발급한다
    2. 카드 결제는 해당 거래의 증빙을 완료한다 (추가 발급 금지)
    3. 정산 차감된 금액이라도 “서비스 대가”면 별도 거래로 본다
    4. 동일 거래에 대한 중복 증빙은 금지한다
    ```
    
    ---
    
    # 🔥 핵심 기준 (이걸로 모든 판단)
    
    ```
    ① 이 돈이 “누가 번 돈인가?”
    ② 그 돈이 “어떤 거래에서 발생했나?”
    ③ 결제수단이 카드인가 / 현금인가
    ```
    
    ---
    
    # 15.4 현재 정책 (카드 결제 only)
    
    ---
    
    ## 15.4.1 게스트
    
    ### 📌 결론
    
    ```
    현금영수증 ❌
    세금계산서 ❌
    ```
    
    ---
    
    ### 📌 이유
    
    ```
    게스트는 카드로 결제했으며
    카드 매출전표가 이미 증빙이기 때문
    ```
    
    ---
    
    ### 📌 적용 범위
    
    - 임대료
    - 게스트 수수료 (9.9%)
    - 옵션 상품
    - 이지스테이 전용 청소서비스
    
    ---
    
    ---
    
    ## 15.4.2 호스트
    
    ---
    
    ## 📌 (1) 임대료 정산금
    
    ```
    발급 ❌
    ```
    
    ### 이유
    
    ```
    임대료 공급자 = 호스트
    플랫폼은 중개자
    ```
    
    ---
    
    ## 📌 (2) 플랫폼 수수료 3.3% (🔥 핵심)
    
    ### ❗ 결론 (확정)
    
    ```
    세금계산서 발급 ⭕
    ```
    
    ---
    
    ### ❗ 이유 (가장 중요)
    
    ```
    이 수수료는
    
    게스트 결제와는 별개로
    
    “플랫폼 → 호스트 서비스 제공 거래”이기 때문
    ```
    
    ---
    
    ### ❗ 핵심 이해
    
    ```
    게스트 결제 → 게스트 거래
    
    수수료 3.3% → 호스트가 플랫폼에 지급한 비용
    → 별도 B2B 거래
    ```
    
    ---
    
    👉 따라서
    
    ```
    카드 결제 여부와 무관하게
    
    세금계산서 발급 대상이다
    ```
    
    ---
    
    ### 📌 발급 방식 (초기에 운영자가 홈택스에 수동으로 발급 예정)
    
    ```
    - 대상: 사업자 호스트
    - 방식: 월 합산 발급
    - 공급일자: 해당 월 말일
    - 발급일: 익월
    ```
    
    ---
    
    ---
    
    ## 📌 (3) 위약금
    
    ```
    발급 ❌
    ```
    
    ---
    
    ### 이유
    
    ```
    손해배상 / 계약정산
    → 과세 거래 아님
    ```
    
    ---
    
    ---
    
    ## 📌 (4) 위약금 결제 시 수수료
    
    ```
    발급 ❌
    ```
    
    ---
    
    ### 이유
    
    ```
    호스트가 카드로 직접 결제한 거래
    → 카드 매출전표로 증빙 완료
    ```
    
    ---
    
    # 15.5 현재 상태 요약
    
    ```
    게스트: 발급 없음
    호스트: 수수료만 세금계산서 발급
    ```
    
    ---
    
    # 15.6 정산과의 관계
    
    ```
    정산 ≠ 증빙
    ```
    
    - 정산은 금액 흐름
    - 증빙은 거래 기준
    
    👉 서로 독립
    
    ---
    
    # 15.7 향후 정책 (계좌이체 / 무통장입금)
    
    ---
    
    ## 15.7.1 게스트
    
    ```
    현금영수증 ⭕
    세금계산서 ⭕ (사업자 한정)
    ```
    
    ---
    
    ### 대상
    
    - 게스트 수수료
    - 옵션 상품
    - 이지스테이 전용 청소서비스
    
    ---
    
    ### 제외
    
    ```
    임대료 ❌ (호스트가 발급)
    ```
    
    ---
    
    ---
    
    ## 15.7.2 호스트
    
    ---
    
    ### 플랫폼 수수료
    
    ```
    세금계산서 ⭕ (사업자 한정)
    ```
    
    ---
    
    ### 개인 호스트
    
    ```
    발급 없음 ❌
    ```
    
    ---
    
    # 15.8 구현 요구사항
    
    - 사업자 정보 저장
    - 세금계산서 월합산 발급 예정이므로 호스트 대상으로 수수료 지급 확정 건이 영수증 발급 메뉴에 저장되어야 함.
    - 환불 시 수정 세금계산서
    
    ---
    
    # 15.9 절대 규칙
    1. 카드 결제 거래에 대한 추가 증빙 발급 금지
    2. 임대료는 플랫폼이 발급하지 않는다
    3. 위약금은 어떤 경우에도 발급하지 않는다
    4. 수수료는 “서비스 거래”로 판단한다
