## 1. Goal

- 옵션 상품 상태에 따라 **자동 환불(결제취소)**과 **반품 신청(관리자 승인)**을 명확히 분리한다
- 상품 단위 선택 기반으로 **여러 주문건을 묶어서 처리 가능**하도록 한다
- 배송 상태 기반으로 **일관된 환불/반품 정책**을 제공한다

---

## 2. User Story

- 게스트는 배송 전 상품을 선택하여 즉시 환불받고 싶다
- 게스트는 배송 중 또는 배송 완료된 상품을 선택하여 반품 신청을 하고 싶다
- 여러 주문건의 상품을 한 번에 선택해서 처리하고 싶다
- 각 상품의 현재 상태와 가능한 액션을 명확히 알고 싶다

---

## 3. Flow

---

### 3.1 옵션 취소 (즉시 환불)

1. 게스트 계약관리 페이지 진입
2. 옵션 취소 모달 진입
3. “결제 취소” 버튼 선택
4. 선택 가능한 상품:
    - 배송전
5. 상품 선택 (복수 가능, 주문건 혼합 가능)
6. 환불 금액 자동 계산
7. 결제 취소 실행 (자동 환불)

---

### 상태 변경

```
배송전 → 결제취소 → 환불완료
```

---

### 처리 규칙

- 배송전 상태만 결제취소 가능
- 배송비 차감 없음
- 회수 프로세스 없음

---

### 3.2 반품 신청

1. 옵션 취소 모달 진입
2. “반품 신청” 버튼 선택
3. 선택 가능한 상품:
    - 배송중
    - 배송완료
4. 상품 선택 (복수 가능, 주문건 혼합 가능)
5. 반품 사유 입력 (필수)
6. 이미지 첨부 (선택)
7. 반품 신청 접수

---

### 상태 변경

```
배송중/배송완료 → 반품 신청중
```

---

## 4.2 입력값

### 결제 취소

- 선택 상품 목록

### 반품 신청

- 선택 상품 목록
- 반품 사유 (필수)
- 이미지 (선택)

---

## 4.3 출력값

- 환불 예상 금액
- 각 상품 상태값

---

## 4.4 정상 흐름

---

### 결제 취소

- 상품 선택
- 환불 금액 계산
- PG 부분취소 실행
- 상태 → 환불완료

---

### 반품 신청

- 상품 선택
- 사유 입력
- 반품 신청 생성
- 상태 → 반품 신청중

---

## 4.5 예외 흐름

---

### 1. 반품 신청 중 상품

- 선택 불가

---

### 2. 혼합 상태 선택

- 불가능 (체크박스 비활성화로 방지)

---

## 5. 상태 정의

---

### 상태 흐름

```
배송전 → 환불완료

배송중 → 반품 신청중 → 반품 전 → 반품 중 → 반품 완료

배송완료 → 반품 신청중 → 반품 전 → 반품 중 → 반품 완료
```

---

### 상태 설명

- 환불완료
→ 물류 발생 없음 / 회수 없음 / 최종 종료 상태
- 반품 신청중
→ 게스트 신청 완료 / 관리자 미처리
- 반품 전
→ 환불 완료 / 회수 필요 상태
- 반품 중
→ 회수 진행 중
- 반품 완료
→ 회수 완료

---

## 6. 관리자 처리

---

### 6.1 반품 승인

- 환불 자동 실행
- 배송비 자동 차감 (7,000원)
- 상태 → 반품 전

---

### 6.2 반품 거절

- 상태 → 반품 신청 이전의 상태값(배송 전 또는 배송완료)

---

### 6.3 결제관리 환불 (강제 환불)

- 환불 금액 수동 입력
- 배송비 차감 없음
- 상태 → 반품 전

---

### 6.4 옵션 상품 상태 변경 기능

👉 신규 필요

- 상품별 상태 변경 가능:
    - 반품 전 → 반품 중 → 반품 완료

---

## 7. 환불 계산 로직 (참고)

---

### 결제 취소

```
refundTarget = 선택 상품 금액 합
deduction = 0

finalRefund = refundTarget
```

---

### 반품 승인

```
refundTarget = 선택 상품 금액 합
deduction = 7000

finalRefund = refundTarget - deduction
```

---

### 관리자 수동 환불

```
finalRefund = 관리자 입력값
deduction = 없음
```

---

## 8. Edge Cases

---

1. 여러 주문건 상품 동시 선택
→ 가능
2. 반품 신청 중 중복 신청
→ 불가
3. 일부 상품만 승인 필요 상황
→ 전체 거절 후 재신청 유도

---

## 9. 개발자 주의사항

---

### 9.1 결제 vs 반품 완전 분리

- 결제취소 = 자동 환불
- 반품신청 = 관리자 승인 or 수동 환불

---

### 9.2 배송비 차감

- 반품 승인 시만 적용
- shipment 기준 1회 적용
- 상품 금액에 분배 금지

---

### 9.3 상태 기반 UI 제어

- 프론트: 체크박스 비활성화
- 백엔드: 상태 검증 필수

---

# 🔥 핵심 요약

👉 배송전 = 즉시 환불

👉 배송중/완료 = 반품 신청

👉 배송비 = 반품 승인 시만 차감

👉 상태 = 환불과 회수를 분리하여 관리
